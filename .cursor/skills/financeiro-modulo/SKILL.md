# Módulo financeiro — Solides CRM

Esta skill cobre **movimentos, baixa de boletos e retorno bancário** do módulo `financeiro/`.

**Aplicabilidade:** somente projetos cujo código tem o módulo `financeiro/` (tipicamente o **Solides CRM**). Confirme no projeto atual (ver perfil `arquitetura/estado-projeto-{projeto}.md`). Projetos sem esse módulo (ex.: adapters, Partners) **não** usam esta skill.
