O usuário mandou usar o Figma para desenho de fluxos, regras de negócio "e o que mais for recomendado". A conta é plano **Starter** com assento View (team::1682818455439403999), o que dá **até 20 chamadas de tool por mês**. O `generate_diagram` (Mermaid → FigJam) funciona. Primeiro board: "Brain — fluxo por card", fileKey XUTaRVVYy549785lXKCZdn.

**Why:** o usuário quer visualização dos fluxos e regras; a cota baixa obriga economia.

**Quando usar (regra do usuário, 25/09):** sempre perguntar antes se vale desenhar no Figma, dizendo por quê, inclusive para board novo. Só quando for extremamente necessário usar sem perguntar, e comunicar logo depois (o que desenhou, link, por quê). Alterar ou apagar board existente sempre pede OK.

**How to apply:** 1 board por card (os demais diagramas entram no mesmo board via `fileKey`); o Mermaid fica no doc em `docs/`, que é o entregável, e o FigJam é a visualização, com link no doc. Nunca ler de volta o que acabou de desenhar. Detalhe do encaixe em `.claude/habilidades.md`.
